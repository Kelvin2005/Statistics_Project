# 论文质量检查与修订记录

检查对象：`docs/red_sea_houthi_shipping_paper.md`

检查维度：

1. 问题明确程度
2. 理论分析支撑性
3. 数据能否验证

## 1. 问题明确程度

### 原稿评价

原稿已经提出“胡塞武装相关安全事件是否影响红海关键航道通行量与绕航行为”这一主问题，但问题表述偏宽，容易让读者误以为论文要识别严格因果效应，或要回答单船风险问题。

### 主要风险

- “通行量下降”和“绕航增加”被放在同一个主问题中，但两者对应变量不同。
- 分船型问题与主线关系较弱，容易显得像额外附加分析。
- 没有把研究问题明确转化为可检验假设。

### 修订动作

已将主问题改为：

```text
胡塞武装相关安全事件增加后，红海航线通行量和好望角绕航指标是否出现可识别的动态变化？
```

并新增三条经验假设：

- H1：安全事件具有持续性。
- H2：安全事件对航道通行结构的影响具有滞后性。
- H3：分船型响应可能存在差异，但当前聚合数据只能检验弱证据。

### 修订后评价

问题链条更清楚：主问题负责总体方向，H1 检查事件序列是否持续，H2 检查绕航动态，H3 检查分船型证据边界。论文不会再把“总体绕航结构”和“单船风险”混在一起。

## 2. 理论分析支撑性

### 原稿评价

原稿的理论部分主要是文献与现实背景，能够说明红海危机重要，但对“为什么袭击事件会影响绕航”的机制解释不够集中。

### 主要风险

- 缺少从安全事件到航线选择的中间机制。
- VAR 和 OLS 模型像是直接套用工具，而不是由理论机制推出。
- 读者可能会问：为什么不直接看曼德海峡下降，而要看好望角上升？

### 修订动作

已新增“理论机制：安全冲击、航运成本与绕航决策”小节，用简化成本框架解释：

```text
期望总成本 = 正常运营成本 + 时间延误成本 + 风险溢价 + 保险成本 + 预期损失
```

并明确说明：

- 红海航线正常运营成本低，但安全事件提高风险相关成本。
- 好望角航线距离长，但在高风险状态下可能成为风险调整后的替代路径。
- 航线调整需要时间，因此影响更可能滞后出现。
- 好望角通行量比单看曼德海峡更适合观察绕航行为。

### 修订后评价

理论分析已经能支撑模型选择。VAR 用于刻画滞后动态，IRF 用于观察冲击后的响应路径，分船型 OLS 用于辅助检验船型差异。

## 3. 数据能否验证

### 原稿评价

原稿已经说明 ACLED 和 PortWatch 的数据来源，也写到了 AIS 不足。但“哪些问题能验证、哪些不能验证”还不够表格化，读者需要自己推断。

### 主要风险

- ACLED 是冲突事件数据，PortWatch 是聚合通行数据，二者无法验证单船层面的因果机制。
- 分船型回归的 R² 较低、系数不显著，应被解释为证据不足，而不是强行解释方向。
- 缺少控制变量，不能声称完整因果识别。

### 修订动作

已新增“本文能验证什么”小节，建立研究问题、变量和可验证程度的对应表：

| 研究问题 | 可验证程度 |
| --- | --- |
| 安全事件是否具有持续性 | 强 |
| 安全事件是否与绕航增加相关 | 中等 |
| 曼德海峡通行量是否下降 | 中等 |
| 不同船型是否响应不同 | 弱到中等 |
| AIS 关闭是否提高遇袭风险 | 当前不能验证 |

同时在方法和结果部分补充：

- 方法设计与 H1、H2、H3 的对应关系。
- VAR 结果支持 H1，并部分支持 H2。
- 分船型回归未稳定支持 H3，因此不能声称某类船型更敏感。

### 修订后评价

数据验证边界更清楚。论文现在可以稳妥地说：现有数据能支持聚合层面的动态相关分析，但不能支持单船风险、AIS 开关影响或严格因果结论。

## 4. 剩余建议

若后续还要继续增强论文，可优先做三件事：

1. 让 `scripts/run_analysis_real.py` 自动保存 IRF 图，而不是只显示图。
2. 加入事件研究或中断时间序列，以 2023 年 11 月红海危机升级为断点。
3. 若能获得运价、保险费率或历史 AIS，再扩展到更强的机制验证。
